## 🚗 Projects

### Voice Controlled Car using Arduino & Bluetooth

A voice-controlled car developed using:

- Arduino
- Bluetooth Module
- Motor Driver
- DC Motors
- Battery
- Mobile Phone

The mobile phone sends voice commands through Bluetooth.
The Bluetooth module receives the commands and sends them to the Arduino.
The Arduino processes the commands and controls the motors through the motor driver.
